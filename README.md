# E-Ticaret Web Projesi (ASP.NET Core MVC)

Bu proje, ASP.NET Core MVC kullanılarak geliştirilmiş, çoklu satıcı (marketplace) mimarisine sahip kapsamlı bir e-ticaret uygulamasıdır.

## 🚀 Kullanılan Teknolojiler

*   **Framework:** .NET 10 (ASP.NET Core MVC)
*   **Veritabanı ORM:** Entity Framework Core
*   **Kimlik Doğrulama:** ASP.NET Core Identity, OpenIddict
*   **Tasarım:** Bootstrap 5, HTML5, CSS3
*   **Mimariler:** Repository Pattern, Session Management, Eager Loading

## 📦 Özellikler

*   Misafir kullanıcılar için Session tabanlı sepet sistemi.
*   Giriş yapan kullanıcılar için sipariş ve ödeme (Checkout) yönetimi.
*   Satıcılara özel ürün ekleme, düzenleme ve ilan yönetimi paneli.
*   Adminler için genel sistem ve kategori yönetimi.
*   Dinamik stok takibi ve sepet kontrolleri.
